# Multilingual Campus Helpdesk Assistant

This is our Innovation Lab project—a simple web chatbot built to help students and visitors quickly find campus information in **English**, **Hindi (हिंदी)**, and **Hinglish**.

## What It Does
- **3 Languages:** Switch anytime between English, Hindi, and Hinglish using the top dropdown.
- **Voice Input:** Click the Mic button to speak your question directly instead of typing.
- **Handles Spelling Mistakes:** Even if someone types a word slightly wrong (like *libraary* or *addmission*), the bot still understands it.
- **Follow-up Memory:** Remembers your previous question, so you can ask *"give me more info"* or *"aur batao"* for extra details.
- **Works on Phone & Laptop:** Adjusts automatically to fit both desktop and mobile screens.

## Topics Covered
- Admission process and required documents
- Semester fee payment and late fine rules
- Exam dates and admit card info
- Library timings and book issue limit
- Hostel room allotment and facilities
- Scholarship verification (NSP & Merit)
- Training & Placement Cell (TPO)
- Campus Wi-Fi, canteen, and bus routes

## Built With
- HTML5
- CSS3
- JavaScript (with browser Web Speech API for voice)

## How to Run
1. Download or clone this repository.
2. Open `index.html` in Google Chrome or Microsoft Edge.
3. Choose your language and type or speak your question.
